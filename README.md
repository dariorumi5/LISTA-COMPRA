**- LISTA-COMPRA**
DESCRIPCIÓN DEL PROYECTO:
Este proyecto consiste en una aplicación Java que permite gestionar una lista de la compra. El usuario puede añadir productos, eliminarlos, buscarlos y vaciar la lista.

CÓMO EJECUTAR LA APLICACIÓN:

Desde Eclipse:
1. Abre el proyecto en Eclipse.
2. Ejecuta la clase GestorListaCompra con clic derecho → Run As → Java Application.

CÓMO EJECUTAR LAS PRUEBAS: 
1. Abre la clase GestorListaCompraTest.
2. Clic derecho → Run As → JUnit Test.ebas
